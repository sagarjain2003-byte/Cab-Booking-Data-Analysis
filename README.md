# Cab-Booking-Data-Analysis
A basic Python project for analyzing cab booking data using Pandas and Matplotlib. It shows booking statistics, revenue analysis, and simple data visualization.
## About Project

I created this project to practice Python and data analysis. The project reads cab booking data from a CSV file and performs basic analysis using Pandas. It also creates graphs using Matplotlib to understand booking patterns and revenue.

## Features

- Read data from CSV file
- Remove duplicate records
- Handle missing values
- Count bookings city wise
- Count bookings by cab type
- Calculate total revenue
- Calculate average fare
- Show booking status
- Generate charts using Matplotlib
- Export processed data to a new CSV file
